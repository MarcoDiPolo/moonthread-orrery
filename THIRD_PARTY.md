# Third-party components

The project builds on the standard PICO CLI Kotlin volumetric template. The original puzzle rules, 3D instrument, panels and launcher design were written for Moonthread Orrery. Its scene contains only programmatically generated PICO primitives. The repository does not redistribute a PICO emulator, SDK archive or third-party 3D asset.
